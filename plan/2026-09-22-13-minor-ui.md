# Plan: Minor UI polish from the #10 live test

## Approved decisions (self-contained summary)

1. **Opaque shortcut sheet.** In `ShortcutSheet.qml` the background alpha goes from
   `0.97` to `1`, still using the theme's `Color.popups.background` channels. At
   0.97, 3% of the list showed through. The sheet already has `z: 5` over the list.
2. **The sheet lists every key.** In `Model.SHORTCUTS`:
   - add, under Move, `{ group: "Move", keys: "tab", text: "Next tab in the full-screen menu; the next bar panel in the popup" }`;
   - change `esc` to "Dismiss Podman's message, leave the filter, then close the
     panel".

   The test "every key the panel actually listens for is written down" gains
   `"tab"`. The README and `docs/usage.md` key tables get the same two lines.
3. **The menu card keeps its top edge.** In `Menu.qml`, `card.y` becomes
   `Math.max(Style.gapsOut, Math.round(panel.height * 0.075))`. The height stays
   capped at `panel.height * 0.85`.
4. **Hold the order under the pointer; the cursor follows its container.**
   - `ResourceList.qml`: a `HoverHandler` on the ListView, exposed as
     `readonly property bool pointerInside`.
   - `PodmanView.qml`: `property var heldIds: null`. When `list.pointerInside`
     becomes true, snapshot the current row ids in order; when it becomes false,
     reset to `null`.
   - `Model.holdOrder(sections, heldIds)` reorders items **within each section**:
     held ids keep their snapshot order, new ids follow in natural order, and gone
     ids drop out. `null` returns the sections unchanged. `PodmanView.sections`
     becomes `Model.holdOrder(<today's sections>, heldIds)`.
   - `Model.cursorFollow(rows, id, index)` returns the index of `id` if it is still
     present, and otherwise `clampCursor(index, rows.length)`. `PodmanView` records
     the cursor row's id whenever the cursor moves, and `onRowsChanged` uses
     `cursorFollow`.
   - This holds on any hover, not only after a click, a deliberate widening of the
     approved decision that the spec recorded.
5. **Podman's refusal reads in full, and `esc` dismisses it.**
   - `Model.errorText` shortens every 64-hex id to 12 characters, then keeps up to
     300 characters instead of 160.
   - The key catcher's `onCloseRequested` in `PodmanView.qml`: help sheet open →
     close it; else `podman.lastError !== ""` → clear it; else close the panel.
     `esc` in the filter field is unchanged.

**Rejected** (don't reintroduce): raising `z` to fix the sheet; vertical centring;
holding only after a click; ignoring second clicks; dropping the running-first sort;
a new dismiss key such as `e`; dropping the id from the error.

**Constraints:** the `AGENTS.md` rules (logic in `Model.js` with Node tests, no
hardcoded colours, docs updated in the same PR). `shortcuts.png` and
`podman-refuses.png` are retaken in #11, not here.

**Live-test safety:** only `demo-*` objects. Screenshot and read every dialog before
any confirm, and send the confirm in a separate call. This change needs no prune.
Snapshot Podman, `shell.json` and the clipboard, restore them, and diff afterwards.
