# Plan: The documentation contradicts itself and the code

## The approved decisions, carried over

Every claim was re-verified against `master`. Corrections from the intent:
arrow keys are **already** in `Model.SHORTCUTS` (`"h  l  ← →"`,
`"j  k  ↑ ↓"`) — the gap is `docs/usage.md:154`. And `Panel.qml` exposes
**seven** IPC verbs, not five.

already overflowing a short card. Capital `X` gets nothing — a reference

returns `"2.00 GB · 500 MB reclaimable"`, so `README.md:36` is right and
`docs/usage.md:111` is wrong.

this plan cannot finish. Both outcomes are specified in step 8.
